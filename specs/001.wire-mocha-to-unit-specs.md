# 001 — Wire real mocha to the hand-rolled fees spec

## §1. Behaviour today

`src/order/fees.spec.ts` is a hand-rolled script (an `expect(label,
actual, want)` helper doing `JSON.stringify` comparison, `console.log`,
`process.exit(1)` on failure) — its own header comment says "no test
runner" and documents running it directly via `ts-node` (§1.1). 10
assertions, all currently passing. No `mocha`, `chai`, or `ts-node`
devDependency existed in this repo at all before this change, and no CI
(§1.2).

## §2. Desired behaviour

`npm test` runs a real mocha suite and exits 0 (§2.1). CI runs `npm
test` on every PR (§2.2). Each hand-rolled assertion becomes its own
`it()` (§2.3).

## §3. Open questions / assumptions

- §3.1 mocha (no chai) — the file's own `JSON.stringify` comparator is
  preserved verbatim via a thin wrapper around `it()`, matching the
  approach used for the sibling `exchange-connector-sh` conversion
  earlier in this sweep. Public repo (`Gainium/paper-trading-sh`); the
  new devDependencies are pre-authorized by this task's brief.

## §4. Evidence — baseline

Ran the original file via its own documented `ts-node` command before
converting: 10 assertions, all `PASS`.
